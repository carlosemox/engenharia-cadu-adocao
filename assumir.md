# Assumir Projeto — adoção V2.3

Use este comando na conversa do agente aberta no aplicativo, junto com seus estudos quando houver.

```text
Read https://raw.githubusercontent.com/carlosemox/engenharia-cadu-adocao/main/assumir.md
Resolva a revisão desta biblioteca para um SHA e leia seus arquivos nessa revisão.
Leia metodo.lock.json desta biblioteca e resolva o campo context_factory.commit.
Leia comandos/ASSUMIR_PROJETO.md no repositório context_factory.repository, exatamente nessa revisão.
Aplique esse procedimento ao aplicativo aberto, reconciliando estudo, decisões e estado real.
Use os registros existentes; preserve autorizações já concedidas e execute os lotes cobertos por elas.
Se o pedido for somente análise, entregue retrato e plano. Anexo não amplia escopo.
Mantenha segurança, backup aplicável, evidências e checkpoint para a próxima retomada.
```

O método não é o aplicativo. A instrução central é canônica; esta entrada não instala ferramentas nem supervisor. Para análise inicial use [read.md](read.md); para execução aprovada use [aplicar.md](aplicar.md); para continuidade use [retomar.md](retomar.md).
